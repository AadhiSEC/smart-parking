Database backup & restore Save a copy of your parking data

Save bookings, customer accounts, prices and blocked spaces in one backup file. You can download a backup while the website is running.

Keep your backup private. It contains customer details and account information. Store a copy on another drive so you can recover it if this computer fails.

Restore a saved backup

Stop the server with Ctrl+C in VS Code, then run the command below. Replace the example path with your backup file's full path, keeping the quotation marks.

python server.py --restore "FULL_PATH_TO_BACKUP.sqlite3"

The command checks the file and shows its date and record counts. Type RESTORE to replace current data, or press Enter to cancel. It saves a safety backup first. After restoring, start the server and sign in using the passwords from that backup.
